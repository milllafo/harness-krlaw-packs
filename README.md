# harness-krlaw-packs

한국 법령 조문 묶음이다. 문서를 검토하는 도구가 '어느 조문을 볼지' 표시할 때 쓴다. 조문 글은 공식 출처에서 받은 글자 그대로 담는다.

- **출처.** 법제처 국가법령정보센터(https://www.law.go.kr) OPEN API. 법령은 시행일 기준 현행 판이다.
- **법률 자문이 아니다.** 위법 · 합법을 판정하지 않는다. 판단은 사람 · 전문가가 한다.
- **최신을 보장하지 않는다.** 묶음마다 적힌 기준일까지만 확인한 것이다.

## 기준일의 뜻

묶음의 `pack.json`에 있는 `checked_at`이 기준일이다. 그날 기계가 묶음의 모든 줄을 공식 출처의 현행 판과 견줬다는 뜻이다.

- 상태가 `현행`인 줄은 그날 공식 출처와 글자가 같았다.
- 글자만 달라진 줄은 기계가 원문을 바꿔 넣고 내용 판(`version`)을 올린다.
- 조문이 없어졌거나 번호 · 제목 · 법령 이름이 바뀐 줄은 `보류`로 막아 두고, 사람이 확인한 뒤에 푼다. `보류` · `폐지` 줄은 근거로 쓰지 않는다.
- 기준일 뒤에 바뀐 것은 여기에 없다. 아직 시행 전인 개정은 `pack.json`의 `upcoming`에 시행일과 함께 적는다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `manifest.json` | 묶음마다 내용 판 · 기준일 · 파일별 sha256. 새 판이 있는지 이 파일 하나로 안다 |
| `packs/<묶음>/pack.json` | 묶음 정의와 상태 — 내용 판 · 기준일 · 법령별 현행 판 시행일 · 보는 조문 · 시행 예정 개정 |
| `packs/<묶음>/basis.csv` | 조문 한 줄씩 — ID · 법령 · 조문 · 조문 제목 · 층위 · 시행일 · 출처 주소 · 상태 · 등급 · 원문 파일 · 원문 해시 · 비고 |
| `packs/<묶음>/text/<ID>.txt` | 조문 원문. 조문 머리 한 줄, 항마다 한 줄, 호는 두 칸 · 목은 네 칸 들여 쓴다 |
| `reports/YYYY-MM-DD.md` | 감시 보고 — 글자가 바뀐 줄 · 보류 · 시행 예정 개정 |

묶음에 요지(줄인 글)는 없다. 정본은 원문이다.
